# International-Post-Pricing (C++)

A decision-support tool designed to calculate global shipping fees based on package dimensions, weight, and destination zones. This project highlights my ability to implement **complex conditional logic** and **mathematical modeling** in software.

### Key Features
- **Global Zone Calculation:** Computes costs across different international shipping zones.
- **Dimensional Weight Logic:** Handles both physical weight and volumetric calculations.
- **Dynamic Fee Estimation:** Includes automated tax and handling fee integration.

### Technical Implementation
- **Conditional Logic:** Extensive use of nested `if-else` and `switch` statements for precise pricing.
- **Arithmetic Precision:** Uses `float`/`double` for accurate currency and weight calculations.
- **User Interaction:** A clean Command Line Interface (CLI) for professional use cases.
